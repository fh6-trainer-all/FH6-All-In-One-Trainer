# FH6 All-In-One Trainer

ImGui overlay trainer for Forza Horizon 6 providing live telemetry edits, garage unlocks, and speed modifiers without altering game files on disk.

## Overlay Controls & Hotkey Map

```yaml
toggle_overlay: Insert
credits_boost: F2
wheelspin_add: F3
teleport_waypoint: F5
```

## Safe Session Workflow

- Launch Forza Horizon 6 first and load into free roam.
- Run the trainer executable as administrator to auto-attach.
- Toggle credits, XP multiplier, or instant win from the overlay tabs.
